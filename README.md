# Design Portfolio (React + Vite)

A responsive, editorial-style portfolio starter inspired by the spacious case-study layout and project archive approach of modern product design portfolios. It is an original implementation, not a copy of the reference site.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder and open it in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Personalise it

- In `src/main.jsx`, replace `yourname`, project names, descriptions, dates and the About text.
- Replace `hello@example.com` with your email address.
- Update the LinkedIn URL in the footer.
- Project artwork is built with HTML/CSS mockups, so you can replace each `visual` with screenshots or images from your actual case studies.
- Update the page title and description in `index.html`.

## Build for production

Run `npm run build`. Vite writes the production site to `dist/`.
